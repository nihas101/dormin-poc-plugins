# Link To The Past Plugin

Ported from: [Mato's Link To The Past Plugin](https://legendsoflocalization.com/research/wanderbar/#the-legend-of-zelda-a-link-to-the-past-super-nes).
This is also where basically all resources contained in this plugin come from.

The client plugin is intended to be run in [BizHawk](https://github.com/TASEmulators/BizHawk) using Snes9X.

# Usage

- Ensure the URL in `client.lua` points to the dormin server you configured
- Copy/Move the contents of this directory into the plugin directory you configured in dormin
- Start the dormin server
- Start BizHawk and add `client.lua` as lua script
- Go to `http://localhost:<dormin-port>/lttp/`
- Install something like [10ten](https://10ten.life/en/) or [yomitan](https://yomitan.wiki/) to get a pop-up style dictionary for the Japanese text in the sidebar
